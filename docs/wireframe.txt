KEY DESIGN FEATURES:
====================

1. CONNECTION STATUS
   [●] Green dot = connected
   Disconnected shows red dot + banner

2. SUMMARY METRICS (Header)
   - Open Positions count
   - Total P&L (large, colored)

3. CELL FLASHING (180ms animation)
   - Green flash = value increased
   - Red flash = value decreased
   - Applied to: Mark price, P&L $, P&L %

4. COLOR CODING
   - LONG side: Green text
   - SHORT side: Red text
   - Positive P&L: Green numbers
   - Negative P&L: Red numbers

5. TYPOGRAPHY
   - All numbers: Monospace, tabular-nums
   - Ensures vertical alignment for quick scanning

6. AI SUMMARY
   - Fixed panel above grid (not modal)
   - On-demand via "Summarize" button
   - 1-3 sentences, observational only

7. INFORMATION FLOW (Top to Bottom)
   Connection → Total P&L → Individual Positions → Actions

8. GLANCEABLE LAYOUT
   - No scrolling needed for 10-15 positions
   - Trader can see entire state in <1 second
   - Exit buttons always visible (right column)
